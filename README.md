# 8 مفاجآت ❤️

رحلة عيد ميلاد تفاعلية من 8 مفاجآت. موقع ثابت (HTML/CSS/JS) بدون أي build.

## التخصيص

كل إشي شخصي موجود بملف واحد: `js/config.js`
- `herName` — اسمها (بيظهر بآخر مفاجأة وعلى ظهر الرسالة)
- `reasons` — السبع أسباب
- `stars` — رسائل النجوم الخمسة
- `memories` — الصور والتعليقات
- `letter` — نص الرسالة
- `candles` — عدد الشموع

### الصور
حط الصور بمجلد `assets/photos` بأسماء `1.jpg` لـ `6.jpg`.
أي صورة مش موجودة بيظهر مكانها إطار ناعم بقلب.
يفضّل تكون الصور مربعة وحجمها أقل من 500KB.

### الرسالة الصوتية
احفظ التسجيل باسم `assets/audio/message.mp3`.
إذا الملف مش موجود، الزر ما بيظهر أبداً.

## التشغيل محلياً
```
npx serve .
```

## ملاحظات
- التقدّم بينحفظ بالمتصفح (localStorage)، فلو سكّرت الصفحة بترجع لنفس المكان.
- لتجربة الرحلة من الأول: افتح الموقع بنافذة خاصة (Incognito).
